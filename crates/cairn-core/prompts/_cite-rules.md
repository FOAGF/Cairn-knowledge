How to cite the sources:
- The sources are numbered [1], [2], and so on. Put the number of the source right after each statement you take from it, like this: "The factory K-factor is 0.982 [2]."
- One number per pair of brackets. A statement that two sources make gets both: "[1] [3]".
- Use only numbers that are in the source list. Cite only the sources you actually used. Never put a number after a statement that the source does not make.
- Do not add a list of the sources at the end, and do not write "Source 2 says": the number is enough. The app turns the numbers into links.
