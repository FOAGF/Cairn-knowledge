# Interface terms: English → 简体中文

The Chinese interface (NFR-I18N-2, D-79) uses these words for Cairn's core terms. Every Chinese string follows this list. A new core term is added here before it is used.

**Status: approved by the owner on 2026-10-25.**

## Style

- **Address the user as 你**, not 您: it is a personal app, and 你 is what most modern apps use.
- **Spacing:** a space between Chinese and Latin letters or numbers ("AI 服务商", "逾期 3 天"); no space next to Chinese punctuation.
- **Punctuation:** full-width in Chinese sentences (，。：？！), with “ ” for quotes. Half-width inside numbers, keys and code (`PRX-12`, `10:30`).
- **Buttons are short verbs:** 保存, 取消, 删除, 恢复. "…" stays on an item that opens a dialog (选择文件夹…).
- **Kept in English:** Cairn, the task type Bug, Markdown, LaTeX, AI, token, the names of providers and models (Azure, Claude, DeepSeek, OpenAI, Ollama), and file types (PDF, DOCX).
